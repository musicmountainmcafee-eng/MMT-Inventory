Inventory script: one last paste (then it updates itself)

  1. Go to script.google.com/home/usersettings and turn Google Apps Script API on.
  2. Open the MMT Inventory script. Project Settings (gear) → tick Show "appsscript.json" manifest file in editor.
  3. Open appsscript.json, select everything, paste box 1 over it. Save.
  4. Open Code.gs, select everything, paste box 2 over it. Save.
  5. In the toolbar's function menu pick setup, click Run, and allow the permissions. The log ends with "Ready".
  6. Deploy → Manage deployments → ✎ → Version: New version → Deploy.

After this, when the dashboard shows “An update for the inventory script is ready”, press Update now. No more pasting.
