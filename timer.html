    Show times
    
        
    Every run plays these times. Change them here and every show updates at once. Type times like 2:00 PM, 8:00 PM; leave a day blank for no show.

    Cue times
    
      
    Clock-time cues are minutes from show time (−60 is an hour before) and roll over by themselves. Timed cues start when the SM presses GO. Curtain speech and acts count up from zero; intermission counts down. Tap Colors under any cue to choose when its clock changes color.
    
      
    
      
    
        
    
      
    
    
    
    

    
    
    
    
      
    Stage managers
    
      
    Pick tonight's stage manager with one tap on the controller. After the show, the report can be emailed or texted to them. Names, emails and phone numbers travel with the schedule (inside the links and over the relay), so keep the links in the building.

    Stream Deck
    
      
    Each button below is a web address. In the Stream Deck app, drag a Website action (under System) onto a key, paste the address, and tick GET request in background. The key then works from anywhere with internet, with no computer needing the timer open. These addresses include the sync code, so tap New code and you'll need to redo them.
    
      
    
      
    If the Stream Deck is plugged into the booth computer with the controller open and in front, Hotkey actions work too: Space GO, B back, H hold, + one minute, − one minute, 1 to 9 the deck calls in order, 0 or Esc clears the call.
    
    
    
    
    

    
    
    
    
      
    Sync between devices
    
      
    Every device on this link shares GO, holds and deck calls. It uses the internet; if the connection drops, each screen keeps counting from the last update it got and catches up when it's back. Anyone with the code can press GO, so keep the link inside the building.
